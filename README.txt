This project is a basic CRUD (Create, Read, Update, Delete) 
interface using a web-based application. The application allows users to add 
new records to a database, view existing records, modify stored information, and delete 
records when they are no longer needed.

There is a difference between regular users and admin users, admin users can view all recods while regular 
users can only view their own information. 

The project uses a combination of PHP, MySQL, html, and css to handle database interactions and create a 
user interface. The purpose of the assignment is to practice connecting a web application 
to a database and implementing the fundamental operations used in database-driven applications.
